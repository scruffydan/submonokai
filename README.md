# SubMonokai

A Sublime Text inspired Monokai colour theme for various applications.

## T3-Code

1. Download [SubMonokai-T3-Code.json](SubMonokai-T3-Code.json).
2. In T3-Code, open **Settings → Appearance** and import the JSON as a custom theme.
3. Select **SubMonokai** and use dark appearance.

See the [T3-Code appearance documentation](https://github.com/pingdotgg/t3code/blob/main/docs/user/appearance.md) for theme settings.

The shared palette is documented in [SubMonokai Colors.md](SubMonokai%20Colors.md).
